# A股每日复盘快照

一个**每日自动更新**的 A 股收盘复盘看板，分享给朋友看。

## 这是什么

每天 A 股收盘后，自动生成一份**当日复盘快照**，包含：

- **题材预判** —— 今日催化消息 → 可能发酵的题材方向 → 先手标的（低位未启动）vs 已启动标的
- **涨跌停全景** —— 涨停/跌停家数、连板梯队、首板明细、炸板统计
- **情绪温度** —— 全市场涨停家数、炸板率、连板高度，判断当天情绪冷热
- **市场广度** —— 涨跌家数、指数走势、板块排行
- **历史趋势图** —— 指数、涨停家数、连板高度、情绪温度的历史曲线

## 怎么访问

| 链接 | 内容 |
|---|---|
| [最新快照](https://ahazx.github.io/stock-review-daily/) | 永远看**最新一天**的收盘复盘 |
| 当日归档（如 `https://ahazx.github.io/stock-review-daily/2026-10-26/`） | 回看**某一天**的复盘 |

## 更新节奏

- 每个**交易日 15:30** 收盘数据定稿后自动生成并发布
- 非交易日（周末、节假日）不更新

## 说明

- 本看板是**收盘定格快照**，非盘中实时数据
- 题材/标的映射基于公开行情数据自动生成，**仅供研究参考，不构成任何投资建议**
- 涨跌颜色遵循 A 股惯例：**红涨绿跌**
